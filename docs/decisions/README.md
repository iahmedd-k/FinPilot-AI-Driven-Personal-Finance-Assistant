# Architecture decision records

Record material architecture decisions here so future contributors can
understand the context, alternatives, and consequences. Do not backfill an
unverified decision from current code. No accepted ADRs were identified during
this documentation pass.

## Create a record

1. Copy [the ADR template](0000-template.md).
2. Use the next available number and a short kebab-case title, for example
   `0001-explicit-cors-allowlist.md`.
3. Set the status to `Proposed` while seeking approval, then update it to
   `Accepted`, `Rejected`, `Superseded`, or `Deprecated`.
4. Link the ADR from the relevant architecture/operations docs and update
   affected records when the decision changes.
